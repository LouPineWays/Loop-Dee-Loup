# Loop-Dee-Loup Idea Intake reference snapshots

This directory contains recovery snapshots of LDL-specific source files maintained in the founder's Loop-Dee-Loup Idea Intake project.

These files are **not repository authority** and are not part of the worker startup contract, Manual, Index, review contract, or execution lifecycle. They exist only as a redundant recovery reference in case the project-side copies are accidentally changed, deleted, duplicated, or otherwise damaged.

Authority rule:

1. Current founder instruction and current repository-local authority win.
2. Normal authoritative LDL files, Issues, PRs, gates, and contracts win over these snapshots.
3. These snapshots must never be used to override newer repository behavior merely because their text differs.
4. A snapshot may be used to reconstruct or compare a project-side source file, after which any proposed promotion into repository authority must follow normal LDL issue/review rules.

The repository intentionally does **not** mirror project files that contain cross-repository routing, other-project details, or broader founder-work context.
